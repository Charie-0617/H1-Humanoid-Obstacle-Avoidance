# 环境搭建

Windows 原生侧跑训练 / 渲染 / VLA；
WSL2（Ubuntu 24.04 + ROS2 Jazzy）为部署端。

## 版本

| 项 | 版本 |
|---|---|
| Isaac Sim | 5.1.0（pip 安装） |
| Isaac Lab | v2.3.2（源码 clone + 装 rsl_rl） |
| torch | 2.7.0+cu128（Python 3.11） |
| NVIDIA 驱动 | 580.88 |
官方推荐580.88，新版本跑不了，记得回退一下显卡驱动

## 安装

```bash
conda create -n isaac python=3.11 -y && conda activate isaac
pip install "isaacsim[all]==5.1.0" -i https://pypi.tuna.tsinghua.edu.cn/simple --extra-index-url https://pypi.nvidia.cn
# clone Isaac Lab v2.3.2 → isaaclab.bat --install rsl_rl
# 接受 EULA：echo "Yes" | python -c "import isaacsim"
```
