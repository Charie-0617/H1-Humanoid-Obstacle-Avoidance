# WSL2 ROS2 部署方案

Isaac Sim 和部署节点都在 WSL2（Linux）内运行，DDS 同环境通信天然通，无需跨系统桥接。

## 架构

```
Isaac Sim (H1 仿真 + ROS2 bridge)
  ├ 发布 /joint_states, /imu, /cmd_vel
  └ 订阅 /joint_cmd → 驱动 H1
        ↕ DDS
ROS2 部署节点 (policy_node + policy.onnx)
  ├ 订阅 /joint_states, /imu, /cmd_vel
  ├ 69 维观测 → ONNX 推理 → 19 维关节目标
  └ 发布 /joint_cmd
```

## 链路

```
cmd_vel → 部署节点(ONNX) → joint_cmd → 仿真器 PD 执行 → H1 行走
```

## 前置

- WSL2 Ubuntu 24.04 + ROS2 Jazzy
- conda `isaac` 环境 + isaacsim 5.1.0 + Isaac Lab v2.3.2
- 部署节点 colcon 构建（onnxruntime-linux 放 deploy_ros2/ 下）

## 运行

编译、启动仿真、启动节点的命令见 `deploy_ros2/README.md`。
